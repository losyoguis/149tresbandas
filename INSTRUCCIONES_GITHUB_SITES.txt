BILLAR TRES BANDAS PRO - PUBLICACIÓN EN GITHUB Y GOOGLE SITES

1. Publicar en GitHub Pages
- Sube todos los archivos y carpetas de esta carpeta a un repositorio de GitHub.
- En GitHub: Settings > Pages > Deploy from branch.
- Selecciona la rama main y la carpeta /root.
- Abre la URL pública que entrega GitHub Pages.

2. Incrustar en Google Sites
- En Google Sites usa: Insertar > Incorporar > URL.
- Pega la URL pública de GitHub Pages del index.html o de la raíz del proyecto.
- Ajusta el alto del bloque embebido. Recomendado: 760 px en computador y ancho completo.

3. Instalar como app móvil
- Abre la URL de GitHub Pages en Chrome Android.
- Menú de Chrome > Agregar a pantalla principal o Instalar app.
- Para jugar mejor en móvil, se recomienda girar el celular horizontalmente.

4. Notas importantes
- El video guía se reproduce mediante iframe de Google Drive. El ZIP queda más liviano porque ya no incluye el MP4 local.
- El video ahora carga con preload=metadata para que la página abra más rápido.
- El Service Worker no descarga el video completo automáticamente; solo cachea núcleo e imágenes consultadas.
- En modo práctica, el botón Demostración reproduce la ruta modelo; el botón Tirar conserva la física real.
